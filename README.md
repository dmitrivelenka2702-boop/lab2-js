# Лабораторна робота №2 з JavaScript

## Завдання
Реалізувати форму додавання нових даних у таблицю.

## Реалізація
Початкові дані зберігаються у масиві `students` у файлі `script.js`.

HTML містить лише структуру сторінки, форму та порожній елемент `tbody`.
Усі рядки таблиці створюються та виводяться динамічно засобами JavaScript.

Після введення нового запису:
1. Дані з форми додаються до масиву `students`.
2. Функція `renderStudents()` повторно формує таблицю.
3. Форма очищується та приховується.

Сторонні бібліотеки та фреймворки не використовуються.
